## Who We Are

**DevoxSec Technologies** is a technology company focused on secure software engineering and practical digital solutions. We work across the software development lifecycle—from design and development to security testing and hardening—helping build applications that are both useful and resilient.

Our approach brings full-stack engineering together with an offensive security mindset. We assess the systems we build with the scrutiny of security testers, with the goal of identifying weaknesses early and improving the quality of every release.

## How We Work

- **Security-minded engineering:** We consider security throughout the software development lifecycle, not only at the end.
- **Full-stack capability:** We work across frontend, backend, mobile, and supporting infrastructure.
- **Offensive-minded testing:** We use practical application security testing techniques to challenge our own builds and assess client systems with appropriate authorization.
- **Quality and value:** We prioritize useful solutions, responsible delivery, and customer satisfaction.
- **Modern practices:** We value maintainable code, dependency hygiene, and disciplined development workflows.

## Security & Responsible Disclosure

Security research and testing must be conducted responsibly.

- Only test systems you own or have explicit permission to assess.
- Do not access, modify, or disclose data beyond the agreed scope.
- Report discovered vulnerabilities through the appropriate authorized channel.
- Allow affected parties reasonable time to investigate and remediate issues before public disclosure.

If you believe you have identified a security issue affecting DevoxSec Technologies, contact us at **securitydevox@gmail.com** with relevant details. Do not include sensitive personal information or live exploit data in a public issue.
